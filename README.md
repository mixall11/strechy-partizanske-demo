# Strechy Partizánske — eshop demo

Štyri vizuálne prototypy homepage pre strešný/klampiarsky eshop. Každá verzia uplatňuje inú marketingovú stratégiu.

## Demá

| Verzia | Štýl | Cieľovka | Hlavná stratégia |
|---|---|---|---|
| [v1 Classic](demo-v1-classic/) | Shoptet baseline | Zmiešaná | Trust + sortiment |
| [v2 Authority](demo-v2-authority/) | Lindab/Manufactum | B2B firmy, projektanti | Authority + lead magnet |
| [v3 Conversion](demo-v3-conversion/) | Notino/Alza | B2C deal-hunters | Scarcity + social proof |
| [v4 Editorial](demo-v4-editorial/) | Apple/heritage | Architekti, premium | Identity + storytelling |
