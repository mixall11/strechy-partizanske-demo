💡 Workflow pre tlač
1. Stiahni SVG (vyššie). 2. Otvor v Adobe Illustrator (File → Open) — všetky farby, krivky, text-y sú editovateľné. 3. Ak chceš text ako tvary (bez závislosti na fonte Inter): Type → Create Outlines (Shift+Ctrl+O). 4. Exportuj PDF (File → Save As → PDF, preset "Press Quality") a pošli do tlačiarne (Wonderprint, Print24, Plotter.sk).
Tip: font Inter stiahni z Google Fonts zdarma — alebo nahraď v AI svojim brand fontom.
